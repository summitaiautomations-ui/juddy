Recruiting Dashboard — Setup
=============================

After this 5-minute setup, the dashboard runs in the background 24/7.
You never need to touch Terminal again -- just open
http://localhost:8800 in your browser whenever you want it.

ONE-TIME STEPS
--------------

1) Install Node.js (skip if already installed)
   - Check: open Terminal, type:  node --version
   - If you see "v20.x" you're set.
   - If "command not found", install the macOS LTS from:
       https://nodejs.org/en/download

2) Create a Notion integration
   - Visit:  https://www.notion.so/profile/integrations
   - Click "+ New integration"
   - Name: Recruiting Dashboard
   - Workspace: yours
   - Type: Internal
   - Submit, then COPY the "Internal Integration Secret"
     (it starts with "ntn_" or "secret_"). Save it for step 5.

3) Share the database with the integration
   - Open the Recruiting Pipeline database in Notion.
   - Top-right "..." menu -> Connections -> "+ Add connections"
   - Pick "Recruiting Dashboard". Confirm.

4) Run Install-Always-On.command
   - Unzip this folder somewhere permanent (e.g. ~/Documents/dashboard).
     Do NOT move it after running the installer (the service points
     at this exact location).
   - Double-click  Install-Always-On.command  in this folder.
   - First time only: macOS may say "cannot be opened because the
     developer cannot be verified." Right-click the file -> Open ->
     click "Open" in the dialog. (Apple's standard quarantine for
     downloaded scripts.)
   - A Terminal window pops up, runs for a few seconds, opens your
     browser to http://localhost:8800, and tells you it's installed.

5) In the dashboard header, click "Enable Notion sync ->"
   - Paste the token from step 2. It saves to your browser only.
   - The pill turns green:  "Notion sync: ON"

You're done. Bookmark http://localhost:8800.

EVERYDAY USE
------------

Just open http://localhost:8800 in your browser. The service is always
running. Drag candidates between stage columns -- each drop syncs to
Notion:

   Offer column   -> auto-sets priority to Hot
   Interview      -> auto-sets priority to Warm
   Passed         -> clears priority

To remove the service later, double-click Uninstall-Always-On.command.

For a one-time launch without installing as a service, double-click
Start-Dashboard.command instead.

If anything goes wrong, share what you see (Terminal output, browser
error) with Claude -- happy to debug.
