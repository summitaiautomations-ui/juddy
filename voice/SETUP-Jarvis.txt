Jarvis -- Setup
===============

Always-listening voice assistant for your recruiting pipeline. Say "Hey Jarvis"
and ask anything: "who needs me today," "what's Sims' status," "add Bob Smith,
twenty-five units, nine million, at Caliber, recruiter Mark Kurth." He searches,
creates, updates, and moves cards in your Notion pipeline.

WAKE PHRASE: "Hey Jarvis"  (the "Hey" part matters)

ONE-TIME SETUP
--------------

1) Install Python 3 (skip if already installed)
   - Check: open Terminal, type:  python3 --version
   - If "command not found", install from:
       https://www.python.org/downloads/

2) Get your two keys

   a. Anthropic API key
      - https://console.anthropic.com/  ->  Settings  ->  API Keys  ->  Create Key
      - Starts with "sk-ant-..."

   b. Notion integration token
      - The same token you set up for the dashboard. If you don't have one yet,
        see the dashboard SETUP.txt for the steps.
      - Starts with "ntn_..." or "secret_..."

3) Save the keys
   - Copy ".env.example" to ".env"  (right-click -> Duplicate, then rename)
   - Open .env in TextEdit and paste your two values, no quotes:
       ANTHROPIC_API_KEY=sk-ant-...
       NOTION_TOKEN=ntn_...

4) Run it
   - Double-click Start-Jarvis.command
   - macOS may say "cannot be opened because the developer cannot be verified."
     Right-click -> Open -> click "Open" in the dialog. (First time only.)
   - Terminal opens. The first run will:
       a. Create a Python virtual environment (~30 seconds)
       b. Install dependencies (~3-5 minutes, ~200 MB)
       c. Download the wake-word model (~10 MB)
       d. Download the Whisper speech model (~150 MB)
   - When you see  Listening for "Hey Jarvis"  you're live.
   - macOS will ask for Microphone access. Allow it for Terminal.

5) Talk to him
   - Say: "Hey Jarvis"  (clear "Hey" then a short pause then your request)
   - You'll hear a chime. Then ask.
   - He will speak back.

EXAMPLES
--------
   "Hey Jarvis, who needs me today."
   "Hey Jarvis, what's the pipeline summary."
   "Hey Jarvis, add Bob Smith, twenty-five units, nine million,
    at Caliber, recruiter Mark Kurth."
   "Hey Jarvis, move Chris Sims to Offer stage."
   "Hey Jarvis, what's Annie Gladden's NMLS."

To stop: Ctrl+C in the Terminal window, or just close the window.
To start again: double-click Start-Jarvis.command.

TROUBLESHOOTING
---------------
- "Microphone permission denied": System Settings -> Privacy & Security ->
  Microphone -> turn on for Terminal.
- Wake word missing your voice: speak the "Hey" clearly and a touch louder.
- He hears you but answers oddly: just tell him on the next turn -- he
  remembers the conversation within a session.
- ANY other weirdness: paste the Terminal output to Claude and ask.
